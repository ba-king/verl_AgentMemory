# 通用 Memory prompt：忠于证据、区分事实与推断

日期：2026-09-06。此次只有一个运行时代码改动：
`memory_agent/prompts/system.py` 增加通用的记忆内容原则。

## 内容与边界

- 准确保留观察到的身份、属性、动作和结果，不写与证据矛盾的断言。
- 区分有直接证据的事实与推断；保留推断时说明它是推断、依据和不确定性。
- 未提及不等于不存在；目标、尝试或未经验证的判断不等于已观察结果。
- 既有 agent 声明和检索记忆不会仅因出现在上下文中就成为独立核实的事实。
- 写入前核对断言，同时保留有用的已知事实，避免因部分信息不确定而全部放弃写入。

这是跨数据集的内容生成要求。未加入任何购物规则、商品类别、具体失败 case、标准答案、特定环境完成标记或评分反馈。
没有新增 JSON 字段或强制记忆模板，推断标注在原有 content 文本内表达。

## 为什么改这里

在 task17 P2 的实际 Memory 请求中，商品名称、前序购买、兼容规则和购买回执均可见，生成结果仍否认商品名称中明确包含的属性。
该证据支持优先修改内容忠实性要求，但不能证明某个完成标记就是模型出错的原因。

本次没有修改 Answer prompt、adapter、BM25、固定括号修复或模型纠正预算。
固定语法修复仍只恢复结构，不检测或纠正事实；不能把结构校验成功当作内容真实。
